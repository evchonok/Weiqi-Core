# 🎮 Weiqi Core

**Weiqi Core** — это веб-приложение для игры в Вейци (Го), решения задач и мини-игр.
Особенностью проекта является встроенный **Хоррор-режим**, который добавляет атмосферу напряжения во время партии с помощью визуальных и звуковых эффектов.

Проект разработан с использованием фреймворка **Ruby on Rails**.

---

## Основные возможности

### Аутентификация
- Регистрация и вход пользователей.
- Защищенные маршруты (доступ к игре только после входа).
- Сессии и безопасное хранение паролей (`has_secure_password`).

### Игра на одном устройстве (Hotseat)
- Реализация правил Вейци: постановка камней, захват групп, правило Ко, запрет самоубийственных ходов.
- **Три размера доски:** 9x9 (обучение), 13x13 (быстрая), 19x19 (классика).
- Автоматический подсчет очков по японским правилам (территория + пленные + коми 6.5).
- Подсветка территории после окончания партии.

### Хоррор-режим
- Уникальный режим игры с нарастающей атмосферой.
- **Динамическая интенсивность:** чем дольше игра, тем страшнее.
- **Эффекты:** затемнение экрана, дрожание камней, фоновый эмбиент.
- **Скримеры:** появляются при захвате камней или ошибочных ходах.
- Модальное окно с предложением перейти в мини-игры после окончания партии.

### Структура модулей
- **Задачник:** Меню для выбора задач (обычный и хоррор режимы).
- **Мини-игры:** Раздел для отдыха (Крестики-нолики, Виселица, Судоку).

---

## Технологический стек

- **Backend:** Ruby 3.4+, Ruby on Rails 8.
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (логика игры работает на клиенте для максимальной отзывчивости).
- **База данных:** SQLite (по умолчанию для разработки).
- **Верстка:** Адаптивный дизайн (Flexbox/Grid).

rails server
